P&ID otomatik çizim — Draw.io (.drawio) üretici

Kullanım
  1. CAD-Dokuman.vbs veya npm start cad
  2. Kod kataloğu: ML/kayitlar/kodlar.json veya KODListesi.csv
  3. Makine tipi seç → componentleri işaretle → P&ID Üret
  4. İndirilen .drawio dosyasını Draw.io eklentisiyle aç, düzenle, export et

Klasörler
  data/       Makine tipi tanımları
  lib/        Sembol + Draw.io XML üretici
  templates/  Referans şablonlar (LYM-1)
  output/     (gelecek) kaydedilen çıktılar

ML entegrasyonu
  "ML Makine JSON" ile kayitlar/*.json içe aktarılabilir.
