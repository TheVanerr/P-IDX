P&ID sembol dosyaları — Draw.io / diagrams.net import

Dosyalar:
  SS01.svg  Reflektörlü el koruma sensörü (standart, siyah)
  SS03.svg  Işık perdesi / ışın bariyeri (opsiyon, kırmızı)

Draw.io'ya ekleme:
  1. Dosyayı sürükleyip çizime bırakın
     VEYA  File → Import from → Device
  2. Özel kütüphane: File → New Library → SS01.svg / SS03.svg sürükle
  3. Etiket: sembolün altına SS01 veya SS03 yazın (ayrı metin)

Not: SS01 ile SS03 aynı sembol değildir; opsiyon/standart ayrımında farklı tag kullanın.
